FLASHING EFFECTS ALERT

THIS GAME CONTAINS INTENSE FLASHING AND STROBE EFFECTS.

Players with photosensitive epilepsy may experience seizures. Proceed with caution.

PSYCHOLOGICAL CONTENT

Silent Tears is not a casual game. It explores:

  • Trauma and mental breakdown
  • Self-harm and suicidal thoughts
  • Psychological manipulation themes

This is presented in a serious, realistic way.

NOT FOR EVERYONE

DO NOT PLAY IF:

  • You are currently struggling with mental health
  • You are easily disturbed or triggered
  • You prefer light-hearted gaming experiences
SYSTEM ACCESS NOTICE

The game accesses limited system data:

  • Your Windows username (for example: C:\Users\YourName)
  • System language settings
  • Save file paths

IMPORTANT: This data is not collected, not shared, and not uploaded. It is used locally only for immersion and personalization.

SAVE FILES

Default save location:

C:\Users\YourName\AppData\Roaming\Silent_Tears

Tip: add ?user=YourName to the URL to show your actual path on this page.

LOCATION DATA

On each launch, the game may determine your approximate location using your public IP address. This information is stored locally only:

C:/Users/YourName/Roaming/Silent_Tears/ip_info.txt

NOT UPLOADED. NEVER SHARED. Used only to enhance immersion.

BAT AND PYTHON SCRIPT BEHAVIOR

Background scripts may:

  • Open your web browser
  • Move your mouse slightly
  • Simulate temporary effects

These are harmless, temporary effects. No files are deleted, installed, or modified. No personal data is accessed.

DISABLE SCRIPTS (NOT RECOMMENDED)

To prevent scripts from running, delete the project_tools folder.

WARNING:

  • Immersion will be significantly reduced
  • The game may crash unexpectedly
  • Some features may malfunction
ANTIVIRUS FALSE ALARMS

This game is not malware. However, because it uses system features such as browser calls, shell commands, and input interaction, some antivirus tools may flag it incorrectly.

Solution: whitelist the game folder in your antivirus or firewall settings, or disable them temporarily while you play.
